# Naming

The working name is **Quorum**, with the package name `quorum-qa`. A quorum is several independent judges, and a finding stands only when it is verified, which is the idea of the tool.

| Candidate | Why | Risk |
|---|---|---|
| **Quorum** | Several judges; decisions by agreement | Common word; likely taken on npm and as a bare domain |
| Tribunal | Judges who verify before ruling | Sounds heavy |
| Crosscheck | Cross-verification | Likely taken |
| Veredicto | Spanish flavour that still reads in English | Harder for an English-speaking audience |

Before choosing a name:
- [ ] npm: `quorum-qa`, or a scoped `@<user>/quorum`
- [ ] GitHub org or repo name
- [ ] a domain (`.dev`)
- [ ] a quick trademark search (USPTO TESS / IMPI in Mexico) in the software class

Renaming the repo later is cheap; renaming a published npm package is not. Settle the name before the first publish.
